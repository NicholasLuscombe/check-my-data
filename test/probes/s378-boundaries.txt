The severity ladder, read from src/analysis/severity.js:17-23
════════════════════════════════════════════════════════════════════════════════════════════════════

  H = HIGH count, M = MODERATE count, D = distinct mechanism dimensions over HIGH+MODERATE.

    severity 3   H >= 2                                    (two HIGHs, any dimensions)
                 H == 1 and D >= 2                         (one HIGH plus a flag elsewhere)
                 H == 0 and M >= 2 and D >= 2              (two MODERATEs, cross-dimension)
    severity 2   H == 1 and D == 1                         (one HIGH, nothing else flagged)
    severity 1   H == 0 and M >= 1, not the 3-case above
    severity 0   H == 0 and M == 0

  So the boundaries a sheet can cross are:
    3 -> 2   drop to exactly one HIGH AND collapse to one dimension
    3 -> 1   drop to zero HIGH, keep a MODERATE, and not be cross-dimension on two of them
    2 -> 1   lose the last HIGH while a MODERATE survives
    1 -> 0   lose every flag of both tiers

  Note the ladder has no rung that MODERATE count alone can move once H >= 2.
  M is read only when H is 0 or 1, so on a sheet at two-plus HIGHs the entire
  MODERATE column is inert.
